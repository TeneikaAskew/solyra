The FEAT-IDs solyra work is filed under. `scripts/gate/spec_gate.py` reads the
IDs from this file: a change to anything but documentation needs a
`feature/<feat-id>-<slug>` or `fix/<feat-id>-<slug>` branch naming one of them,
unless it only touches dependency manifests, lockfiles or the gate's own files
(`chore/`).

surface, copied from stocks `main` at `3cf471d` on 2026-09-27, plus CI / testing
(FEAT-CICD-001), which this repository's workflows, tests and build configuration
are filed under. The stocks catalog is canonical: each ID links to its full
record there. The four other backend-only capabilities (Alerts / Discord, Data
platform, Infrastructure / deploy, Technical debt) are omitted. One copied value
is corrected: the stocks FEAT-UI-001 row still lists solyra #26 and #27 as open
blockers, and both closed on 2026-09-14.
