# Feature Catalog (solyra)

**Last reviewed:** unknown · **Last scanned:** 2026-09-28 · **Owner:** TBD

The FEAT-IDs solyra work is filed under. `scripts/gate/spec_gate.py` reads the
IDs from this file: a change to anything but documentation needs a
`feature/<feat-id>-<slug>` or `fix/<feat-id>-<slug>` branch naming one of them,
unless it only touches dependency manifests, lockfiles or the gate's own files
(`chore/`).

These are the rows of the [stocks catalog](https://github.com/TeneikaAskew/stocks/blob/main/docs/product/02-FEATURE-CATALOG.md) whose UI column names a
surface, copied from stocks `main` at `3cf471d` on 2026-09-27, plus CI / testing
(FEAT-CICD-001), which this repository's workflows, tests and build configuration
are filed under. The stocks catalog is canonical: each ID links to its full
record there. The four other backend-only capabilities (Alerts / Discord, Data
platform, Infrastructure / deploy, Technical debt) are omitted. The Open issues and Top
blockers columns were re-copied from stocks `main` at `08f3e880` on 2026-10-08, the merge
of the open-issue map's regeneration.

The last two columns are this repository's own. Phase 5 of the product-delivery
skill updates a row's Status and Last reviewed and adds each merged PR's number
to PRs. They start at `unknown` and `none`: no solyra PR has been recorded
against a row yet.
